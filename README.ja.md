# Pitatto

[English](README.md) | **日本語**

macOS の前面ウィンドウを、ショートカット 1 つで最大化したり画面の端に寄せたりする常駐アプリ。
同じキーを続けて押すと、大きさが 1/2 → 1/4 → 3/4 と変わる（サイクル）。
左右は幅、上下は高さが変わる。最大化は 全体 → 余白 64pt → 余白 24pt と変わり、画面の中央で四辺に余白を空ける。
サイズを名指しするキーも別に割り当てられる。

| 操作 | 既定のキー |
| --- | --- |
| 最大化 | ⌃⌘↩ |
| 左に寄せる | ⌃⌘← |
| 右に寄せる | ⌃⌘→ |
| 上に寄せる | ⌃⌘↑ |
| 下に寄せる | ⌃⌘↓ |
| 左のデスクトップへ移動 | ⌃⇧⌘← |
| 右のデスクトップへ移動 | ⌃⇧⌘→ |

最大化はメニューバーと Dock を除いた領域いっぱいまでで、macOS のフルスクリーンにはならない。
デスクトップへの移動では、画面もウィンドウと一緒に隣のデスクトップへ切り替わる。システム設定の
キーボードショートカット > Mission Control で「左の操作スペースに移動」「右の操作スペースに移動」がオンになっている必要がある。
入口はメニューバーのアイコンで、Dock にアイコンが出るのは設定ウィンドウを開いている間だけ。
通信はアップデートの確認とダウンロードのみ。

## 動作環境

macOS 14 以上。ウィンドウを動かすのにアクセシビリティの許可が要る。
初回はメニューの「アクセシビリティを許可…」からシステム設定を開いて、Pitatto をオンにする。

## インストール

[Releases](https://github.com/senkentarou/pitatto/releases) から `Pitatto-<version>.zip` を
ダウンロードし、展開した `Pitatto.app` を `/Applications` に置く。

## アップデート

起動時と 1 日 1 回、新しいリリースを確認する。あればメニューに「新しいバージョン x.y.z があります…」が出て、
アップデートウィンドウが開く。そこの「更新して再起動」でダウンロードと入れ替えをする。
メニューの「アップデートを確認…」でいつでも確認できる。

## ビルド

```
make check   # lint・ビルド・テスト
make run     # /Applications に置いて起動
```

`make app` と `make run` は `.app` に署名する。既定の署名 ID は `Pitatto Dev` で、
キーチェーンアクセスの「証明書アシスタント」で 1 度だけ作るコード署名用の自己署名証明書を指す。
手元にある別の証明書を使うなら環境変数で渡す。

```
CODESIGN_IDENTITY="Developer ID Application: ..." make run
```

ad-hoc 署名（`-`）は使わない。署名がビルドのたびに変わると、macOS は別のアプリとみなして
アクセシビリティの許可を落とす。

`Sources/PitattoCore` が判断を持ち、import は Foundation と CoreGraphics だけ。`Sources/Pitatto` が
OS 呼び出しを持つ。Core にそれ以外の import があると `make lint` が落ちる。

`Pitatto.app/Contents/MacOS/Pitatto --print-frame [app]` は前面ウィンドウ（アプリ名かバンドル ID を
渡せばそのアプリのフォーカスされたウィンドウ）の位置とサイズを AppKit 座標の `x y width height` で
1 行に出す。スナップ先の確認に使う。

## 設定

メニューバーのアイコンから「設定…」。変更はその場で効く。

- 一般: ログイン時に起動、アクセシビリティの許可の状態
- ショートカット: 最大化と寄せるの 2 枚の表で、操作ごとに 1 行。サイクルの列が上の表のキーで、
  最大化の全体・余白 64pt・24pt と、寄せるの 1/2・1/4・3/4（計 15 個）は既定では何も割り当てていない。
  その下にデスクトップへの移動 2 行
- クレジット

欄を押してからキーを押すと変わる。⎋ で取り消し、⌫ で割り当てを消す。

刻みは寄せるが 1/2・1/4・3/4、最大化が全体と余白 64・24pt の固定で、変えられない。アプリの最小ウィンドウサイズを
下回る大きさはその最小値に丸めて端に付けるので、どの刻みがどう効くかは画面の広さとアプリ次第になる。
